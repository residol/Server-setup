# Bellion Network - Complete Setup

Benvenuto nella distribuzione completa del server Minecraft multi-gamemode "Bellion" a tema castle-fantasy medievale, ottimizzato per Pterodactyl Panel.

## Struttura Directory
```
Bellion-Complete-Setup/
├── plugins/           # Plugin .jar (core, gamemode, custom)
├── configs/           # Configurazioni server, eggs, plugin
├── worlds/            # Mappe pregenerate
├── database/          # Schema SQL e dati
├── scripts/           # Script di startup, backup, manutenzione
├── documentation/     # Guide admin, player, tecnica
├── resource-packs/    # Resource pack opzionali
└── INSTALLATION-GUIDE.md
```

## Quick Start
1. Segui la guida in `INSTALLATION-GUIDE.md`
2. Importa lo schema SQL in MySQL
3. Carica plugin, mondi e configs
4. Usa gli eggs JSON su Pterodactyl Panel
5. Avvia la network con gli script forniti
