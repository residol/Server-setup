# Bellion Scripts

Questa directory contiene tutti gli script bash per la gestione, il backup e la manutenzione della network Bellion.

- `start-all.sh`: Avvia tutti i server
- `stop-all.sh`: Ferma tutti i server
- `restart-server.sh`: Riavvia un server specifico
- `start-server.sh`: Avvia un singolo server con parametri ottimizzati
- `backup.sh`: Backup automatico di dati, plugin, mondi e configurazioni
- `maintenance.sh`: Aggiornamento e validazione plugin/config

Esegui questi script dalla root del progetto o tramite Pterodactyl Panel per una gestione rapida e sicura.
