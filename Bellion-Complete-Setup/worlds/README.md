# Bellion Worlds

Questa directory contiene tutte le mappe pregenerate per le varie modalità della network Bellion.

- hub: Castello medievale centrale
- bedwars: 20+ mappe a tema medievale
- skywars: 15+ isole fluttuanti tema sky-castle
- kitpvp: Arena medievale con ostacoli
- buildbattle: Plot e arene per build
- arena1v1: 10+ arene piccole
- vanilla: Mondo survival ottimizzato
- prisonskyblock: Mondo ibrido con mine e isole

Carica qui le cartelle dei mondi. Ogni server Paper deve avere la sua cartella world dedicata.
