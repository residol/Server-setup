# PrisonSkyblock Core Plugin

Plugin custom per la modalità ibrida Prison x Skyblock di Bellion.

## Features
- Dual Progress System (Mine-to-Sky)
- Resource Bridge
- Rank Islands
- Gang Islands
- Prestige Wings
- Dual Economy

## Build
Compila con Maven:
```
mvn clean package
```
Il .jar risultante va posizionato in `../../plugins/`.
