# Bellion Economy Bridge Plugin

Plugin custom per la gestione della valuta cross-server Bellion (Coins, Gems, Honor Points, Build Tokens).

## Features
- Sincronizzazione economia tra tutti i server
- Integrazione Vault API
- API per plugin custom
- Supporto shop cross-server

## Build
Compila con Maven:
```
mvn clean package
```
Il .jar risultante va posizionato in `../../plugins/`.
