# Bellion Cosmetics System Plugin

Plugin custom per la gestione di cosmetics medievali (trails, pets, hats, wings) su Bellion.

## Features
- Trails, pets, hats, wings a tema medievale
- GUI integrata con DeluxeMenus
- Sistema di effetti particelle (ProtocolLib)
- Cross-server sync

## Build
Compila con Maven:
```
mvn clean package
```
Il .jar risultante va posizionato in `../../plugins/`.
