# Arena1v1 Manager Plugin

Plugin custom per la modalità Arena PvP 1v1 di Bellion.

## Features
- 10+ arene con ostacoli
- Instant-kill weapons (spade one-hit)
- Queue system automatico
- Spectator & betting system
- ELO ranking
- Tournament mode
- Replay system

## Build
Compila con Maven:
```
mvn clean package
```
Il .jar risultante va posizionato in `../../plugins/`.
