# Bellion Configs

Questa directory contiene tutti i file di configurazione necessari per il deployment e la gestione della network Bellion su Pterodactyl Panel.

- `bellion-bungeecord.json`: Egg per il proxy BungeeCord
- `bellion-paper.json`: Egg per i server Paper
- `bellion-network.json`: Egg per il deployment automatico della network
- Altri file di configurazione server e plugin

Copia questi file nelle rispettive sezioni del Pterodactyl Panel per una configurazione rapida e senza errori.
